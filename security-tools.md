# Security Tools

Tools for application and code security.

## Static Analysis

- **SonarQube** - Code quality and security
- **Snyk** - Security vulnerability scanner
- **CodeQL** - Semantic code analysis
- **Semgrep** - Pattern-based scanning

## Dependency Scanning

- **npm audit** - Node.js vulnerability check
- **Dependabot** - Automated updates
- **Renovate** - Dependency updates
- **OWASP Dependency-Check** - Vulnerability detection

## Secret Scanning

- **git-secrets** - Prevents secrets in commits
- **truffleHog** - Finds secrets in repos
- **detect-secrets** - Secret detection
- **Gitleaks** - Git secret scanning

## Container Security

- **Trivy** - Container scanning
- **Clair** - Vulnerability scanner
- **Falco** - Runtime security

## Penetration Testing

- **Burp Suite** - Web security testing
- **OWASP ZAP** - Web app scanner
- **Metasploit** - Penetration testing

## Authentication

- **Auth0** - Identity platform
- **Keycloak** - Identity management
- **Okta** - Identity provider
