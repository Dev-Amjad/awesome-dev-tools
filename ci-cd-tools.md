# CI/CD Tools

Tools for continuous integration and deployment.

## CI Platforms

- **GitHub Actions** - Native GitHub CI/CD
- **GitLab CI** - GitLab's CI/CD
- **Jenkins** - Open source automation
- **CircleCI** - Cloud CI/CD
- **Travis CI** - CI for open source

## Deployment

- **Vercel** - Frontend deployment
- **Netlify** - Web deployment
- **Railway** - App deployment
- **Render** - Cloud deployment
- **Fly.io** - Global deployment

## Container Orchestration

- **Kubernetes** - Container orchestration
- **Docker Swarm** - Docker clustering
- **Nomad** - Workload orchestration

## Infrastructure as Code

- **Terraform** - Infrastructure provisioning
- **Pulumi** - Modern IaC
- **Ansible** - Configuration management
- **CloudFormation** - AWS IaC

## Monitoring

- **Datadog** - Monitoring platform
- **New Relic** - Observability
- **Grafana** - Visualization
- **Prometheus** - Metrics collection
