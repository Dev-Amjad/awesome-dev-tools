# API Development Tools

Tools for building and testing APIs.

## API Testing

- **Postman** - API platform for testing
- **Insomnia** - REST and GraphQL client
- **Thunder Client** - VS Code REST client
- **HTTPie** - Command-line HTTP client

## API Documentation

- **Swagger/OpenAPI** - API documentation
- **Redoc** - OpenAPI documentation
- **Stoplight** - API design platform

## Mocking

- **Mock Service Worker** - API mocking
- **JSON Server** - Fake REST API
- **Mockoon** - Mock API server

## GraphQL

- **Apollo Studio** - GraphQL IDE
- **GraphQL Playground** - Interactive IDE
- **Altair** - GraphQL client

## API Gateway

- **Kong** - API gateway
- **Tyk** - API management
- **AWS API Gateway** - Managed gateway
