# Docker Tools

Essential tools for Docker development.

## Container Management

- **Docker Desktop** - GUI for Docker management
- **Portainer** - Web-based container management
- **Lazydocker** - Terminal UI for Docker

## Orchestration

- **Docker Compose** - Multi-container applications
- **Kubernetes** - Container orchestration
- **Docker Swarm** - Native clustering

## Development

- **docker-compose-wait** - Wait for services
- **Dive** - Explore Docker image layers
- **Hadolint** - Dockerfile linter

## Registry

- **Docker Hub** - Public registry
- **GitHub Container Registry** - GitHub's registry
- **Harbor** - Private registry

## Monitoring

- **cAdvisor** - Container metrics
- **Prometheus** - Monitoring system
- **Grafana** - Visualization
