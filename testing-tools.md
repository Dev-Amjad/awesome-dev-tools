# Testing Tools

Essential tools for testing your applications.

## JavaScript Testing

- **Jest** - Delightful JavaScript testing
- **Mocha** - Feature-rich test framework
- **Vitest** - Blazing fast unit testing
- **Cypress** - E2E testing
- **Playwright** - Cross-browser testing

## Python Testing

- **pytest** - Python testing framework
- **unittest** - Built-in testing
- **nose2** - Extends unittest

## API Testing

- **Supertest** - HTTP assertions
- **REST Assured** - REST testing for Java
- **Pact** - Contract testing

## Code Coverage

- **Istanbul/nyc** - JavaScript coverage
- **coverage.py** - Python coverage
- **Codecov** - Coverage reporting

## Mocking

- **Sinon.js** - Stubs, mocks, and spies
- **Mock Service Worker** - API mocking
- **VCR** - Record HTTP interactions

## Load Testing

- **k6** - Modern load testing
- **Artillery** - Scalable testing
- **Locust** - Python load testing
